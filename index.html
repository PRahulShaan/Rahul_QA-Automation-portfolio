01 — About

    
Quality is a discipline,
not a checkpoint.

  

  

    

      
I'm a Senior QA Automation Engineer with 7.9 years of experience designing, building, and executing manual and automated test frameworks across Investment Banking, Retail Banking, and E-Commerce domains.

      
My core strength is turning fragile, manual regression cycles into dependable, maintainable automation — using Selenium WebDriver, Core Java, Cucumber BDD, TestNG, and the Page Object Model (POM). I extend that coverage into the API layer with RestAssured and Postman, validate data integrity at the database layer with SQL, and wire it all into Jenkins and Maven pipelines so quality gates run on every build, not just before release.

      
Day to day, I work inside Agile/Scrum teams — sprint planning, stand-ups, retrospectives — owning the full test lifecycle from requirement traceability (RTM) and test case design through defect lifecycle management in JIRA. I'm as comfortable authoring a hybrid automation framework as I am tracing a UI defect back to a bad row in a database.
